## 1. 背景与调研结论

### 产品背景

短剧广告投放中，投手每天要面对：巨量 / 磁力(快手) / 腾讯多平台规则差异、海量素材的审核合规、ROI 波动的归因排查。这些经验散落在人脑、群聊和历史数据里，新人难复用、老人靠记忆。松鼠投放把这些沉淀成一个**随时能问、答案一致、越用越聪明**的 AI 投放伙伴。

### 竞品调研摘要

对标 **AiDSO（爱搜）** 的诊断报告（散点图 + 热力图 + 竞品对标 + 多指标卡）作为质量标杆。选定产品方向：

- **对话优先（问）**：全屏对话 + 左侧历史 + 顶栏全局平台切换，问出价 / 审核 / 数据 / 复盘
- **报告化诊断（诊）**：素材上传 → 违规可视化定位 → 改造建议 → 过审预测
- **职责分层**：监控 = 事实层（是什么），复盘 = 判断层（为什么 / 好不好 / 怎么办），互不越界
- **视觉**：B 端系统规范表达，主色品牌蓝 `#2563EB`，避免营销展示感

### 技术选型（原型阶段建议，正式开发待定）

| 层 | 当前原型 | 正式开发建议 |
|---|---|---|
| 前端 | 原生 HTML / CSS / JS（自包含 design-system） | Vue 3 / TypeScript |
| 后端 | 无（纯前端模拟数据） | Python / FastAPI / PyCore |
| LLM | 无（脚本模拟回复） | 待选型（意图路由 + RAG） |
| 知识库 | 静态 mock | L1/L2/L3 三级 + 向量检索 + 重排 |
| 平台对接 | mock | 巨量 / 磁力 / 腾讯 开放 API |

### 页面跳转图

```text
[进入] → P02 智能问答（默认首页）
            │  顶栏全局：平台切换（巨量/磁力/腾讯/全平台）+ 视角切换（角色）
            ├─ 问"能否过审" ───────→ P03 素材诊断
            ├─ 问"为什么掉/复盘" ──→ P05 投放复盘
            └─ 问"数据" ───────────→ P04 数据监控
P05 投放复盘 ──「一键执行」下发 ──→ P04 数据监控（追踪 ROI 回升）
P04 数据监控 ──「账户下钻」───────→ 账户详情（趋势 / 留存 / 明细）
左侧导航按「视角(角色)」过滤可见模块
```

### 全局布局结构

- **共享外壳**：左侧 `#__sidebar`（按角色过滤的导航）+ 顶栏 `#__topbar`（全局平台切换器 + 视角切换 + 用户）
- **平台全局化**：投手锁定单平台，管理者可切「全平台汇总」，状态存 `localStorage(squirrel_platform)`
- **视角全局化**：`localStorage(squirrel_role)` 驱动左侧导航过滤，和团队管理的权限矩阵一一对应

## 4. Mission、Persona 与版本规划

### Mission

把散落在人脑、群聊、历史数据里的短剧投放经验，沉淀成一个随时能问、答案一致、越用越聪明的 AI 投放伙伴，让投手少踩坑、新人快上手。

### Persona

| 角色 | code | 关注 | 典型动作 |
|---|---|---|---|
| 投放主管 | admin | 多平台全局、团队效率 | 切全平台看汇总、配权限、看复盘 |
| 投手 | toushou | 单平台跑量、过审、ROI | 问出价 / 诊素材 / 看监控 / 做复盘 |
| 审核 | audit | 合规、拒审应对 | 素材诊断、查审核红线 |
| 运营 | ops | 数据、知识沉淀 | 看监控、维护知识库 |

### 版本规划

- **V1 MVP**：问（P02）+ 诊（P03）+ 监控（P04）+ 复盘（P05）+ 知识库（P06）+ 账户（P07）+ 团队（P08）+ 设置（P09）
- **V2**：工作台（P10）+ 智能预警（P11，当前已并入监控异常焦点条）

## 5. 复杂功能业务链路与关键实现思路

### 5.1 智能问答意图路由（F-02-01/02）

```text
用户提问 → 意图识别（23 个细分意图）→ 命中知识层级(L1平台规则/L2团队战术/L3个人经验)
        → 选定输出样式(15 种 ASK-XX) → RAG 取证 + 来源标注 → 渲染卡片
模糊 → 追问气泡；越界 → 诚实兜底；不合规 → 婉拒 + 合规替代
```

### 5.2 素材诊断链路（F-03-03）

```text
上传图片 → 关键元素识别(OCR/视觉) → 比对平台审核规则 + 历史拒审案例
        → 违规点定位(图上标注) → 改造建议(硬违规+建议项) → 过审率预测(改造前后)
```

### 5.3 复盘 Agent 归因（F-05-01）

```text
ROI 异常 → Agent 自主 5 步：判断(锁定指标) → 查证(实时数据+历史+大盘)
        → 发现(因子拆分) → 结论(根因) → 建议(可执行+止损区间) → 一键执行 → 监控追踪
```

## 9. 核心流程图

### 问答主流程

```text
提问 → 意图路由 → 知识检索 → 输出样式渲染 → 来源可溯 → (按需)跳专业页
```

### 平台 / 角色全局切换

```text
顶栏切平台 → 写 localStorage → reload → 全站 scope 收敛到该平台

```

### 复盘闭环

```text
监控发现异常 → 复盘 Agent 归因 → 一键执行下发 → 回监控追踪 ROI 回升
```

## 10. 技术风险与缓解

| 风险 | 缓解 |
|---|---|
| 意图识别准确率 | 23 意图分层 + 模糊追问兜底 + 诚实不知道（不瞎编） |
| 知识库时效 / 冲突 | L1/L2/L3 分层，来源可溯，越界明确兜底 |
| 视频审核需求 | 暂不支持上传，转文字描述 + 人工接入，预期对齐不夸大 |
| 监控误判 | 监控纯数据不做判断，判断收口到复盘 Agent |
| 多平台数据口径 | 平台全局化 scope，golden-data 一致性账本保证跨页自洽 |
