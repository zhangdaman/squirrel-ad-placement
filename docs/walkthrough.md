## 2. 知识库（`/knowledge`）
- [ ] 左侧**三级导航**：L1 平台规则库（巨量/磁力/腾讯）/ L2 公域经验库（行业基准/拒审案例）/ L3 私域经验库（题材/出价/素材/复盘/审核/群聊/偏好）
- [ ] 计数：点任一分类，右侧「共 N 条」与左侧数字**一致**
- [ ] 私域内容：L3 能看到「复盘报告 / 审核经验 / 群聊会议」类卡片
- [ ] **上传弹窗**：点右上「上传文档」→ 顶部「来源类型」二选一；切到「💬 非结构化·群聊会议」，下方处理说明变成「对话清洗 + 说话人对齐」
- [ ] 卡片标题无 `[Mock]` 前缀
