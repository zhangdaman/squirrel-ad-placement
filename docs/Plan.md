## 三、前端开发清单

| 任务 | 范围 |
|---|---|
| FE-01 | 共享外壳：`renderShell` 注入 sidebar（按角色过滤）+ topbar（平台切换器 + 视角切换），全局态存 localStorage |
| FE-02 | 智能问答：SSE 流式渲染、15 种输出样式（ASK-01~15）、历史会话（切换/置顶/删除）、来源抽屉、@账户、高风险二次确认 |
| FE-03 | 素材诊断：上传（仅图片，拦视频）、批量概览三档、单图报告 6 模块（违规可视化定位 / 清单 / 建议 / 历史 / 预测）、异常兜底 |
| FE-04 | 数据监控：账户明细表、24h 趋势、留存 cohort（天数 / 日期模式横向滑动）、数据明细——**纯数据，禁渲染任何判断标签** |
| FE-05 | 投放复盘：Agent 归因报告（5 步）、修改建议、一键执行（→ 跳监控追踪）、导出 PDF |
| FE-06 | 知识库：搜索 + 5 个筛选 chip 下拉、知识卡片（chunk/引用/反馈） |
| FE-07~09 | 账户中心、团队权限矩阵（8×4）、系统设置 + 登录页 |

### 前端自动验收标准

- 切平台 → 全站数据 scope 收敛到该平台；admin 才能切 all
- 切视角 → 左侧导航按权限矩阵过滤，无权模块不渲染
- 问答传视频字段 → 前端拦截 + 引导文字 / 人工
- 监控页 DOM 中不出现「异常 / 偏弱 / 建议」等判断词
- 每页 div 平衡、内联 `<script>` 通过 `node --check`

## 四、后端开发清单

| 任务 | 范围 |
|---|---|
| BE-01 | 认证（JWT）+ 平台 / 角色 scope 中间件（按 X-Platform 收敛、按角色鉴权 403） |
| BE-02 | 问答：意图识别（23 意图）→ 知识层级路由 → RAG 取证 → SSE 输出 + 来源 |
| BE-03 | 素材诊断：图片校验（拦视频）→ 视觉/OCR → 比对审核规则库 + 历史案例 → 报告 |
| BE-04 | 数据监控：对接三平台 API 取数，**只返事实数据，不返判断字段** |
| BE-05 | 复盘归因：Agent 5 步编排（判断→查证→发现→结论→建议）+ 一键执行下发 |
| BE-06 | 知识库：L1/L2/L3 入库 + 向量检索 + 重排 + 反馈回流 |
| BE-07 | 账户授权、团队成员、权限矩阵 |

### 后端任务验收规则

- 所有响应符合统一格式；错误码语义正确（401/403/422）
- `X-Platform=all` 且非 admin → 403
- 诊断接口收到视频 / 非图片 → 422 + 引导文案
- 归因报告数值与 golden-data 自洽

## 五、功能详情

### FE-02 / BE-02：智能问答核心链路

```text
提问 →（BE）意图识别 23 类 → 命中知识层级 L1/L2/L3 → 选输出样式 ASK-XX
   → RAG 取证 + 来源 → SSE(intent→step→chunk→source→done)
   →（FE）按 style 渲染对应卡片 + 来源抽屉
模糊→追问气泡；越界→诚实兜底；不合规→婉拒+替代；视频→422 引导
```

### FE-05 / BE-05：复盘 Agent 归因链路

```text
入口(监控异常/问答跳转) →（BE）Agent 5 步：判断→查证(实时+历史+大盘)→发现(因子拆分)→结论→建议(含止损区间)
   →（FE）归因报告渲染 + 每条建议「一键执行」→ POST /review/execute → 置「已下发」+ 跳监控追踪 ROI
```
